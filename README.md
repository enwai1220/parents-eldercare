# 父母养老保障体系

> 父母养老不是一份保险清单，而是一套能在你没有第一时间到场时，依然让父母安全、体面、被妥善照护的系统。

## 这个仓库是什么

这是一个面向中国家庭的**父母养老保障体系**文档仓库，覆盖：

- **保险规划**：百万医疗险、防癌医疗险、惠民保、意外险的选择与对比
- **应急响应**：从"出事→被发现→通知到你→当地联系人到场→现场处理"的完整链路设计
- **日常健康管理**：慢病管理、体检计划、家庭医生签约
- **财务安全**：财务状况摸底、大额支出预案
- **信息管理**：父母档案模板、多端同步

## 仓库结构

```
父母养老保障/
├── 保障体系总览.md     ← 核心文档，完整阅读入口
├── 保险/               ← 保险产品分析与保单管理
├── 医疗/               ← 体检计划、慢病管理、用药记录
├── 应急/               ← 家庭应急指南、联系人清单
├── 财务/               ← 财务状况摸底与资金预案
├── 档案/               ← 证件信息、重要文件位置
└── 执行/               ← 待办清单与执行记录
```

## 使用说明

1. 从 **保障体系总览.md** 开始阅读，了解完整框架
2. 各子目录的 README.md 说明该模块的用途
3. 目录中的模板文件包含占位符，填入真实数据后使用
4. 执行清单中的待办项可逐项打勾推进

## 维护节奏

- **紧急事项**：任何时候发现需要更新，直接修改
- **季度检查**：每季度检查一次保险扣费、药品余量、联系人信息
- **年度复审**：每年全面审查一次，更新体检报告、保险续保、财务状况
