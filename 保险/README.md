## 核心原则

1. **健康告知是第一优先级**，不可硬推产品
2. 优先选择"保证续保20年"的产品
3. 百万医疗险无法通过健康告知时，替代方案：防癌医疗险 → 惠民保 → 意外险
4. 意外险建议父母必买，一两百元/年

## 常见问题

### 父母有高血压/糖尿病还能投保吗？
需要看具体产品的健康告知。部分产品对"已控制的高血压"或"无并发症的糖尿病"可通过智能核保。如果不确定，走智能核保不留记录。

### 超过60岁还能买百万医疗险吗？
部分产品支持到65岁（蓝医保、泰康百万医疗），众安尊享e生支持到70岁，但非保证续保。

### 已经买了惠民保还需要百万医疗险吗？
需要。惠民保是兜底（门槛高、报销比例低），百万医疗险是主力。两者不冲突，可以叠加。
