## 基础医疗配置

1. **城镇职工/居民医保** — 必须交，这是基础
2. **医保定点医院** — 确认父母附近医院是医保定点
3. **慢性病门诊备案** — 帮父母办好高血压/糖尿病等慢性病门诊备案，报销比例更高
4. **家庭医生签约** — 社区医院的家庭医生签约服务，免费或极低费用

## 慢病管理要点

- 高血压：每日测血压 + 每季度门诊复查
- 糖尿病：每周测血糖 + 每季度查糖化血红蛋白
- 高血脂：每半年查血脂
- 骨质疏松：每年骨密度检查（中老年女性尤其重要）
- 心脑血管：每年心电图 + 颈动脉超声
