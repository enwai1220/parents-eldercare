# 体检计划

## 分年龄建议

| 年龄 | 频率 | 重点项目 |
|------|------|---------|
| 50-60岁 | 每年1次 | 基础体检 + 胃肠镜（每3-5年） + 肿瘤标志物 |
| 60-70岁 | 每年1次 | 基础体检 + 心脏彩超 + 颈动脉超声 + 肺部CT |
| 70岁以上 | 每年1次 | 基础体检 + 认知功能评估 + 跌倒风险评估 + 骨密度 |

## 注意事项

1. 不要只买体检套餐，要根据父母已有问题定制
2. 陪父母去体检，或在当地找人陪
3. 体检报告出来后，**你亲自看一遍**，找出异常项
4. 异常项标记后，预约对应科室复查
