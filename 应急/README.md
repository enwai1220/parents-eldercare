# 应急响应

## 核心链路

```
父母出事 → ① 被发现 → ② 通知到你 → ③ 通知当地联系人 → ④ 现场处理
```

## 目录

| 文件 | 说明 | 隐私级别 |
|------|------|---------|
| 家庭应急指南.md | 可打印版，贴父母家 | 含占位符，填数据后建议 private |
| 当地联系人.md | 同城可到场人员清单 | 含占位符，填数据后建议 private |

## 四路通知机制

1. **手机铃声+震动** — 父母设为紧急联系人，开启 SOS 功能
2. **智能穿戴设备** — 手表/手环跌倒检测自动通知
3. **第三方监控** — 智能摄像头异常推送 + 家庭群组每日报平安
4. **备份** — 邻居/亲友有你电话，床头贴纸

## 当地联系人选择优先级

1. 同城兄弟姐妹/亲戚 — 必须有备用钥匙
2. 父母信任的邻居 — 距离极近
3. 你的同城朋友 — 提前认识父母
4. 社区居委会/物业管家
5. 社区医院/社区卫生站
