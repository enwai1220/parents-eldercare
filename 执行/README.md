# 执行清单

## 维度

| 文件 | 说明 |
|------|------|
| 待办清单.md | 当前阶段待办事项，按优先级排列 |
| 已办记录.md | 已完成事项的时间线记录 |

## 执行节奏

| 阶段 | 时间 | 重点 |
|------|------|------|
| 第一阶段 | 本周 | 紧急响应（SOS、联系人、钥匙、呼救器） |
| 第二阶段 | 1-2周 | 医疗险（体检报告、健康告知、投保） |
| 第三阶段 | 1个月内 | 日常管理（档案、慢病、体检、财务） |
| 第四阶段 | 每季度 | 检查维护 |
| 第五阶段 | 每年 | 全面复审 |

## 使用说明

1. 打开 待办清单.md，按顺序逐项执行
2. 完成一项后，将该项标记为 [x]
3. 所有事项完成后，移入 已办记录.md 并注明完成日期
4. 进入下一阶段
