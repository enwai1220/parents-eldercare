# 待办清单

> 按优先级排列，完成一项标记为 [x]

## 第一阶段（本周）：紧急响应

- [ ] 1. 确认父母手机 SOS 功能已开启
（iPhone: 设置 → SOS紧急联络 → 按5次侧边键呼叫）
（Android: 设置 → 安全与紧急 → 紧急SOS）

- [ ] 2. 你手机把父母设为紧急联系人，确保不静音
（iPhone: 健康App → 医疗急救卡 → 编辑紧急联系人）
（Android: 设置 → 安全与紧急 → 紧急联系人）

- [ ] 3. 打印《家庭应急指南》贴父母家
（文件位置：应急/家庭应急指南.md）

- [ ] 4. 微信建群：你 + 父母 + 当地联系人

- [ ] 5. 购买/准备随身一键呼救器（父母佩戴）

- [ ] 6. 确认至少 2 个当地联系人愿意帮忙

- [ ] 7. 给当地联系人备用钥匙或密码锁密码

## 第二阶段（1-2周）：医疗险

- [ ] 1. 收集父母体检报告和病历
- [ ] 2. 对照健康告知，判断能否投保百万医疗险
- [ ] 3. 选择产品，完成投保
- [ ] 4. 若不可投 → 投保防癌医疗险 + 惠民保
- [ ] 5. 给父母购买意外险（含意外医疗）
- [ ] 6. 保存保单，告诉父母基本保障范围
- [ ] 7. 确认父母医保正常缴纳

## 第三阶段（1个月内）：日常管理

- [ ] 1. 建立父母档案（电子版）
- [ ] 2. 确认父母慢性病门诊备案
- [ ] 3. 签约社区医院家庭医生
- [ ] 4. 列出常用药清单，检查药品余量
- [ ] 5. 安装智能摄像头（与父母沟通好）
- [ ] 6. 预约父母体检
- [ ] 7. 了解父母财务状况，做好资金预案

## 第四阶段（每季度维护）

- [ ] 1. 检查父母手机 SOS 设置是否正常
- [ ] 2. 确认当地联系人联系方式是否变动
- [ ] 3. 检查药品余量，及时补充
- [ ] 4. 和父母视频聊天时顺便问身体状况
- [ ] 5. 检查保险扣费是否正常

## 第五阶段（每年维护）

- [ ] 1. 更新父母档案
- [ ] 2. 带父母体检（或安排当地陪检）
- [ ] 3. 确认保险续保
- [ ] 4. 更新当地联系人意愿
- [ ] 5. 检查应急指南内容是否过时
- [ ] 6. 梳理父母财务状况
