## 核心原则

1. 父母的钱足够日常开销 + 小额应急即可
2. 万一需要大额支出，你要能快速调动资金
3. 提前和父母商量好：**紧急情况下你拥有资金调动权**

## 大额支出预案

可能场景：住院押金、转院费用、护理费用、康复费用

准备：
- 流动资金：至少 5-10 万可随时动用
- 信用卡：额度足够覆盖押金
- 了解父母医保异地就医备案流程
